1. VISION & BIG IDEA
================================================================================

Echoes is NOT a text-to-speech tool or generic AI assistant. It is a digital
memory-preservation platform where emotionally intelligent voice AI turns
ordinary moments into cinematic narrated experiences.

Today people store photos, videos, chats, and voice notes — but they rarely
preserve emotions, atmosphere, storytelling, and human warmth. Echoes fills
that gap by combining:

  • Netflix-style documentary narration
  • Spotify Wrapped–level emotional framing
  • Apple Memories nostalgia
  • Murf AI as the emotional engine (voice is the product, not a feature)

Judges and users should feel something — not evaluate a productivity wrapper.

Opening line for demos:
  "Photos preserve how moments looked. Echoes preserves how they felt."

Shareable hook:
  "Make your life sound like a Netflix documentary."

  }

6. API PIPELINE (CREATE STORY)
================================================================================

  POST /api/stories
    1. Validate originalText
    2. Optional: autoDetectEmotion → Azure OpenAI
    3. enhanceStory(text, style, emotion, language) → Azure OpenAI
    4. ensureNarrationLanguage(enhancedStory, language) → translate if non-English
    5. generateSpeech(...) → Murf API
    6. createStory(...) → write to data/stories.json
    Returns: { story, voiceError? }

  Murf voice IDs (examples, resolved live from API):
    en-US-natalie, hi-IN-shweta, es-ES-carla, fr-FR-justine, de-DE-lia

8. KNOWN ISSUES & MITIGATIONS
================================================================================

  AZURE CONTENT FILTER
    Wholesome family memories (grandfather, "last conversation", loss) can
    trigger Azure Responsible AI policy (content_filter / 400).
    Mitigations in code:
      - G-rated system prompts (lib/azure-safety.ts)
      - wrapUserMemory() framing on all user content
      - Retry with gentler/shorter prompts on same Azure deployment
      - fallbackEnhance() local template if enhancement fails
      - Memory DNA returns emotion-based defaults if blocked
      - generate-voice returns voiceError (not 500) if translation blocked

  MURF AUDIO URLS
    Temporary URLs; may expire. Regenerate voice from story page if needed.

  LOCAL STORAGE
    stories.json is single-file, not suitable for production scale.

  WINDOWS DEV
    Project path has spaces — use one dev server, delete .next if chunk errors.

  HINDI / MULTILINGUAL
    Requires Azure translation to Devanagari BEFORE Murf; English text +
    hi-IN locale produces Indian-accent English (bug that was fixed).
